# 03. 비주얼 언어

## 스타일 고르기

**주 스타일 1개와 보조 기법 1~2개**로 정한다. 여러 스타일을 섞으면 화면이 복잡해질 뿐이다. 13가지 스타일의 특징과 업종 궁합은 [refs/styles-2026.md](refs/styles-2026.md)에 정리했다.

빠른 선택표:

| 제품 성격 | 주 스타일 | 보조 기법 |
|---|---|---|
| 이야기가 있는 B2B / AI 도구 | 에디토리얼 | 스크롤 필름, 그레인 |
| 제품 하나가 주인공인 하드웨어 / 신제품 | 스크롤 3D | 다크 테크 또는 에디토리얼 |
| 기능이 여러 개인 SaaS | (히어로) 에디토리얼 또는 다크 테크 | 중간 섹션에 벤토 그리드 |
| 에이전시 / 포트폴리오 / 행사 | 키네틱 타이포 | 그레인 |
| 친근해야 하는 핀테크 / 헬스 / 키즈 | 클레이 (일러스트에만) | 그레인 |

2026년의 흐름은 이렇다. 에디토리얼(세리프 제목), 키네틱, 스크롤 3D는 **떠오르는** 스타일이다. 다크 테크와 벤토는 **이미 흔해졌다**. 브루탈, 클레이, Y2K는 **포인트로만 쓰는** 스타일이 됐다.

## 타이포그래피

| 역할 | 서체 | 규칙 |
|---|---|---|
| 디스플레이 | **Hahmlet** 200/300/400 (한글 세리프, OFL) | 주로 300을 쓴다. 자간은 KO -0.022em, EN -0.045em, 행간 1.16 |
| 본문 / UI | **Pretendard Variable** 100–900 (OFL) | 제품 섹션의 제목은 650, 자간 -0.055em |
| 라벨 | **DM Mono** 400/500 (OFL) | 대문자, 자간 0.16–0.28em, 9–13px |

- 크기는 `clamp()`로 잡는다. 히어로 `clamp(40px,4.2vw,68px)`(폰 `clamp(24px,6.6vw,38px)`), 장면 제목 `clamp(32px,4vw,64px)`, 포스터 워드마크 `clamp(40px,11.4vw,190px)`.
- **한국어 본문은 17–18px 아래로 내리지 않는다.** 근거는 Apple KR 실측값 17/1.59, 리드 21/600이다. 본문 행간은 1.68–1.8.
- `word-break: keep-all`을 전역에 건다.
- 그림 위에 놓이는 헤드라인에는 3겹 소프트 섀도를 준다.
  `0 1px 2px rgba(8,10,14,.55), 0 3px 12px rgba(8,10,14,.5), 0 10px 46px rgba(8,10,14,.42)`
- 서체는 셀프 호스팅 woff2와 `font-display: swap`으로 싣는다. Next.js라면 `next/font/local`을 쓴다.

## 컬러

두 겹으로 나눈다.

1. **랜딩 고유 팔레트**(시네마틱, 에디토리얼)
   - 밤 / 필름 배경: `#0a0c10` 근처의 거의 검정. 단, 순수한 검정은 쓰지 않는다.
   - 잉크 `#1b1d21`, 뮤트 `#6b7280`.
   - 종이 `#fffdf7`, `#efe0bf`, `#fdf8ec`. 따뜻한 크림을 여러 단계로 둔다.
   - **브랜드 포인트 1색**. 단계 점, 활성 표시, CTA 호버에만 쓴다.
2. **제품 디자인 시스템 토큰**(`--ds-*`): 스플래시, 투어, 제품 UI에 쓴다. 제품에 디자인 시스템이 있으면 거기서 토큰을 받아온다.

규칙:
- 섹션마다 **배경의 온도**를 바꿔 챕터를 구분한다. 필름은 어둡게, 페이퍼 모드는 크림, 투어는 밝은 웜 그레이, 포스터는 짙은 네이비처럼 나눈다.
- 헤더 크롬은 배경에 따라 색을 뒤집는다. 필름 위에서는 흰색, 종이 위에서는 잉크색, 포스터 위에서는 숨긴다.
- **채도는 제품에게만 준다.** 세계를 무채색(종이, 먹, 강조 1색)으로 두고, 채도 높은 색은 제품 색 하나만 쓴다. 그 색이 제품에서 인물, 배경으로 번지는 순간을 이야기의 전환점으로 삼는다. 브랜드 인상과 제품 설명이 한 장면에 같이 들어간다.
- 그림자에도 색을 준다. 캐릭터에는 따뜻한 갈색 `drop-shadow(0 2px 4px rgba(120,80,40,.3))`, 제품 창에는 `0 24px 64px -36px #26332655` 같은 식이다.

## 에디토리얼 장치 (돈 안 드는 고급감)

- **레지스트레이션 그리드**: 화면에 1px 헤어라인(`rgba(255,255,255,.16)`)과 크롭 마크 "+"(`.40`)를 둔다. 인쇄물 감각을 준다.
- **세로 챕터 태그**: 화면 가장자리에 `CH. I`과 `03 · 보고`를 세로로 쓴다.
- **번호 캡션**: `01 · 업무 접수`. 모노 서체에 빨간 점을 찍는다.
- **에디션 칼럼**: 본문 옆에 작은 메타 정보를 둔다. 예: "내 에이전트 · 오전 7:40".
- **페이퍼 모드**: 증거 비트에서 필름을 왼쪽으로 줄이고(≈0.51배) 오른쪽 칼럼에 카피를 놓는다. 잡지 스프레드처럼 보인다.
- **라운드는 거의 각지게**: CTA 6px, 제품 창 10px. 둥근 모서리가 많을수록 앱 같아 보이고 에디토리얼 느낌은 줄어든다.

## 질감

- **필름 그레인**(0.035), **비네트**(0.3), 하프톤 점(7px 셀)은 아주 약하게, 항상 깔아 둔다. 디지털 렌더링의 매끈함을 지워 준다.
- 스크린샷을 그림 안에 합성할 때는 따뜻한 multiply 틴트 `rgba(255,206,140,.17)`, 대각선 유리 글레어(screen blend), 폰에는 `blur(.35px) saturate(.94) contrast(.97)`를 준다. 이렇게 해야 사진이 그림과 같은 공기 속에 있는 것처럼 보인다.
- WebGL을 쓰지 않는 그레인은 SVG `feTurbulence` 노이즈 레이어로 낸다.

## 그래픽 노블 칸 룩

판화·펜 해칭 그림을 만화 칸에 담아 스크롤로 넘기는 룩이다. 브랜드 런칭처럼 이야기가 핵심인 Film에 맞다.

- **톤은 선 밀도로만 만든다.** 면을 색으로 칠하지 않고 해칭 간격과 굵기로 어둡게 한다. 피부나 옷 같은 한두 곳만 단색 톤을 깐다.
- **칸 테두리는 손으로 그린 선**이고, 선이 그려지면서 칸이 들어온다. 칸끼리 겹치거나 화면 밖으로 넘쳐도 된다.
- **한 순간을 두 거리에서 보여 준다.** 큰 칸(전신, 공간) 위에 작은 인셋 칸(얼굴, 손)을 겹친다. 한 화면에 정보가 두 겹 들어간다.
- **내레이션 상자**는 흰 바탕에 굵은 잉크 테두리다. 첫 두세 단어만 강조색으로 칠해 읽기 시작점을 잡는다. 상자는 DOM 텍스트로 둔다(수정, 번역, 접근성).
- 선 그림은 캔버스 버퍼를 **화면의 1.5배 이상**(DPR 1 화면에서도)으로 그린다. 해칭이 계단지지 않는다. 비용은 픽셀 수 2.25배다.

## 페이퍼 콜라주 룩 (pasteup)

- **단색 필드 하나**(대담한 색: 코발트, 토마토, 머스터드 등). 페이지 전체나 섹션마다 필드 하나를 쓴다.
- 요소는 **흑백 하프톤 컷아웃**(약 45–70 lpi 원형 점)에 기계로 자른 듯한 깔끔한 가장자리를 준다. 얇은 흰 종이 테두리를 둘 수도 있다.
- 그림자는 코드로 입힌다. 같은 깊이 레이어의 요소는 그림자 값을 같게 한다.
- **장면 하나에 아이디어 하나.** 장면을 끌고 가는 건 시각적 말장난이다.
- 라벨은 굵은 그로테스크 서체(Archivo Black, Space Grotesk 등)로 쓰고, 한국어는 굵은 고딕으로 쓴다. 이미지 안의 글자로 넣지 않는다.
- 브랜드 포인트 색은 필드 색이 맡거나, 요소 하나에만 쓴다.

## 깔끔형 비주얼 (Clear 버전의 기준)

"차분한 생산성"으로 읽히게 만든다. 장식을 빼고 **표면과 규칙**만으로 완성도를 낸다.

- **팔레트**: 따뜻한 무채색 단계, 깊은 브랜드 1색, 액센트 계열 하나로 구성한다. 채도 높은 SaaS 블루는 쓰지 않는다.
  - 크림 `#fffef7`(히어로), 흰색 `#fff`(섹션), 스톤 `#fafaf9` / `#f5f5f4`
  - 헤어라인 `#e7e5e4` / `#d6d3d1`
  - 브랜드 커피 브라운 `#3d261c`(호버 `#523729`). H2, CTA, 어두운 밴드에 쓴다
  - 액센트 앰버: 카드 `#fffbeb`, 강조 `#fef3c7`
  - 텍스트 `#1c1917` / `#57534e` / `#78716c`
- **깊이는 그림자가 아니라 표면 색의 변화로 만든다.** 크림 → 흰색 → 앰버 카드 → 어두운 밴드 → 흰색 → 어두운 푸터 순으로 리듬을 준다. 그림자는 팝오버에만 쓴다.
- **미디어 틀을 하나로 통일한다.** 모든 기능 스크린샷을 같은 앰버 카드(`rounded-xl`, `aspect-[16/10]`)에 넣고, 아래쪽에 붙여서 카드에서 "솟아오르게" 둔다. 에셋이 평범한 PNG여도 페이지가 디자인된 것처럼 보이는 이유가 이 통일이다.
- **타입**: Pretendard 하나로 간다.

  | 요소 | 값 |
  |---|---|
  | H1 | 30→64px, 700, 행간 1.04, 자간 −0.045em |
  | 서브라인 | 22→30px, 400, 브라운 |
  | 섹션 H2 | 36–40px, 700, −0.025em, 브라운 |
  | 카드 H3 | 24/32px, 600, −0.02em |

  레퍼런스는 본문이 14px로 작았다. **우리 Clear 버전은 본문 16px 이상**으로 하고, 한국어 긴 문단은 17px 이상으로 한다.
- **컨테이너**: 기능 섹션은 1024px, 히어로와 데모는 1280px, FAQ는 1120px. 섹션 위 여백은 64–80px.
- **라운드**: 카드 12px, 데모 셸 20px, 버튼과 칩은 full pill.
- **푸터 장식**: 어두운 배경에 22px 도트 그리드(radial-gradient, 흰색 8%)를 깔고, 방사형 마스크로 가장자리를 흐리게 한다.
- 한 페이지 안에서 Film의 에디토리얼 장치(세리프, 레지스트레이션 그리드)와 깔끔형을 섞을 때는 Hybrid 규칙을 따른다. 토큰은 하나로 쓰고, 세리프는 히어로에만 쓴다.
