# pasteup (tmoody1973/pasteup)

- 저장소: https://github.com/tmoody1973/pasteup (MIT). 확인한 커밋은 `1e4bd86` (2026-07-07)
- 정체: Claude Code 플러그인이다. **하프톤 페이퍼 콜라주 스톱모션** 클립을 만든다. 영상 생성 모델 없이 이미지 요소만 생성하고, 움직임은 결정적인 코드 컴포지터(Pillow + ffmpeg)로 조립한다.
- 설치: `/plugin marketplace add tmoody1973/pasteup`, `/plugin install pasteup@pasteup` (Gemini API 키가 필요하다)

## 룩

- **평평하고 대담한 단색 필드 하나** 위에, 깔끔하게 잘린 **흑백 하프톤 컷아웃**을 부드러운 드롭섀도로 띄운다.
- **장면 하나에 아이디어 하나.** 장면을 끌고 가는 것은 시각적 말장난이나 컨셉이다.
- 완성된 그림을 흔드는 게 아니라 **빈 화면에서 조각이 하나씩 들어와 프레임을 조립**한다. 라벨이 마지막에 놓인다.
- 1950~60년대 편집 포스터, 잡지 콜라주 감성이다.

## 가져올 원칙

### 1. 요소 먼저 만들고, 프레임은 조립한다
- 완성 프레임을 통째로 생성하지 않는다. **요소를 하나씩** 흰 배경에, 그림자 없이, 평평한 조명으로 생성한 뒤 배경을 지워 투명 PNG로 만든다.
- 필드 색, 그림자, 라벨은 **코드가 입힌다.** 그래서 장면이 몇 개든 모두 픽셀 단위로 같다. 요소 PNG에 그림자가 구워져 있으면 그림자가 두 겹이 되고 룩이 깨진다.
- 라벨은 이미지 모델이 그린 글자가 아니라 **진짜 타이포**로 넣는다.

### 2. 스톱모션 케이던스 (수치)

| 항목 | 값 |
|---|---|
| 포즈 간격 | **2프레임마다**(24fps 기준 초당 12포즈). 3프레임마다로 하면 더 투박하다. 매 프레임 갱신은 금지한다(부드러우면 수공예 느낌이 사라진다) |
| 포즈별 지터 | 약 1.5px, 0.4°, **시드 고정**. 프레임이 아니라 포즈에 붙는다 |
| 착지 | easeOutBack으로 약 8% 오버슈트한 뒤 1~2포즈 안에 안착한다 |
| 그림자 | 날아오는 동안 넓고 흐렸다가, 착지하면 지정값으로 좁혀진다 |
| 순서 | 한 번에 하나씩 0.35~0.6s 간격으로 들어온다. 큰 구조물이 먼저, 결정적 디테일이 끝에서 두 번째, 라벨이 마지막이다 |
| 입장 | 가장 가까운 프레임 가장자리에서 들어온다. `enter_path`(베지어 스윕)와 `enter_spin`(180°는 던진 카드, 360°는 구르는 레코드)을 쓸 수 있다 |
| 마무리 | 완성 프레임을 1.2s 이상 유지한다. 지터는 계속 돈다 |
| 카메라 | **움직이지 않는다.** 필드는 고정이고 조각만 움직인다 |
| 그레인 | 0.03~0.05(종이 섬유 느낌) |
| 그림자 값 | 깊이 레이어마다 고정한다. 예: `dx 6, dy 6, blur 10, opacity .30`. 높이 떠 보이게 하고 싶을 때만 바꾼다 |

### 3. 레퍼런스를 스펙으로 분해하기 (Phase A)
"이 프레임을 처음부터 다시 만들려면 무엇을 지정해야 하나?"를 기준으로 분해한다. 필드 색 hex, 하프톤 밀도(lpi), 컷 엣지, 그림자 수치, 레이아웃, 라벨 서체를 모두 **개별로 바꿀 수 있는 JSON 필드**로 적는다. "비슷하게 만들어 줘"는 구조 필드를 유지하고 표면 필드(요소, 아이디어, 라벨)만 바꾸는 작업이 된다. 우리 룩 스펙([templates/look.md](../../templates/look.md))도 같은 태도로 쓴다.

## 랜딩에 옮기는 법

- **영상으로 굽지 않고 DOM에서 실시간으로 조립한다.** 요소는 `<img>`(투명 WebP), 필드는 배경색과 노이즈, 그림자는 `filter: drop-shadow()`로 처리한다.
- 케이던스는 CSS `animation-timing-function: steps(n)`이나 JS에서 진행값을 포즈 단위로 양자화(`pose = floor(t * 12) / 12`)해서 낸다. 지터는 포즈 인덱스를 시드로 한 해시로 계산한다. 그래야 스크롤을 거꾸로 해도 같은 지터가 나온다.
- 트리거: Clear 버전에서는 섹션이 화면에 들어올 때 한 번 조립한다(IntersectionObserver). Film·Hybrid 버전에서는 스크롤 진행값으로 조립을 스크럽한다.
- 요소는 이미지 생성 도구로 만든다. `text-to-image`(Nano Banana Pro, GPT-Image-2)로 만들고, `image-edit`에 레퍼런스를 넣어 팔레트를 고정하고, `bg-removal`(Bria)로 배경을 지운다. 요소 하나에 약 3크레딧 + 배경 제거 비용이고, **영상 크레딧은 0**이다.
- reduced-motion일 때는 완성 프레임을 바로 보여준다.
